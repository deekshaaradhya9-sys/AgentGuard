AgentGuard — AI Agent Security Gateway

AgentGuard is a security gateway designed to protect users from unsafe actions performed by autonomous AI agents. It detects intent drift and prompt injection, evaluates action risk, enforces tool permissions, and pauses sensitive operations for human approval. Its explainable decisions classify actions as ALLOW, REQUIRE_APPROVAL, or BLOCK, helping make AI agents safer and more trustworthy.

Technology Stack

- React and Vite
- Python and FastAPI
- Git and GitHub

Key Features

- Intent drift detection
- Risk scoring
- Permission firewall
- Human approval gate
- Adaptive agent trust
- Security scenario testing
